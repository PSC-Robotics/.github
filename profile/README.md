# PSC Robotics

PSC Robotics is the robotics team at Peter Symonds College in Winchester, UK. We build
autonomous robots in the style of the Student Robotics competition, and we're hosting the
**PSC Robotics Competition 2027**, *Hungry Hippos*, on 11 April 2027 at Peter Symonds College.

- Website: [psc-robotics.uk](https://psc-robotics.uk)
- The competition: [psc-robotics.uk/competition](https://psc-robotics.uk/competition)
- Rules and challenges: [psc-robotics.uk/competition/rules](https://psc-robotics.uk/competition/rules)
- Docs for teams: [docs.psc-robotics.uk](https://docs.psc-robotics.uk)
- Instagram: [@psc_robotics](https://www.instagram.com/psc_robotics)

## Repositories

| Repository | What it is |
| --- | --- |
| [PSC-Comp-OS](https://github.com/PSC-Robotics/PSC-Comp-OS) | The Raspberry Pi image that runs on PSC Robotics robots, based on the Student Robotics image, with a web UI, Wi-Fi hotspot and camera calibration. |
| [Custom-SR-Library](https://github.com/PSC-Robotics/Custom-SR-Library) | `psc-sr-robot3`, our version of the Student Robotics Python library, with support for the PSC brain board. Install it with `pip install psc-sr-robot3`. |
| [hungry-hippos-sim](https://github.com/PSC-Robotics/hungry-hippos-sim) | A Webots simulator of the Hungry Hippos arena, for testing robot code before your robot is built. |
| [Outline-Github-File-Embeds](https://github.com/PSC-Robotics/Outline-Github-File-Embeds) | Changes to our docs site (Outline) so it can embed SVG files from GitHub. |

Some of our software and rules are adapted from [Student Robotics](https://studentrobotics.org).
